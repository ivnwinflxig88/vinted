# Mac 本地 AdsPower 四环境管理工具

在你自己的 Mac（支持 M 系列和 Intel）上，通过 AdsPower Local API 创建并逐个打开 `Vinted-01`、`Vinted-02`、`Vinted-03`、`Vinted-04`。无需 Python 第三方依赖，也不需要导入模板。

## 使用：打开、连接、创建

1. 下载项目 ZIP 并解压。需要保留整个文件夹，包括 `web` 子目录。
2. 打开 AdsPower，进入 **API & MCP**，确认付费套餐的 Local API 已启用。生成 API Key，并保持安全校验开启。
3. 双击文件夹里的 **`启动.command`**。如果双击不能运行，在终端输入 `bash `（末尾有空格），将该文件拖到终端，再按回车。
4. 工具会自动打开本机管理页面。保持终端窗口开启，在页面填写 AdsPower 的 **API 端口**（通常是 `50325`）、**API Key**，选择自己实际使用的 Vinted 站点，然后点击 **连接并检查环境**。
5. 查看四个名称的状态，点击 **创建缺少的环境**。只会创建缺少的名称，不修改、覆盖或删除已有环境。若已经有同名环境，请先确认其中的账户；存在多个同名环境时会停止操作。
6. 按顺序点击四张卡片的 **打开环境，手动登录**，分别登录你希望对应的账户。环境名称只用于管理，不会替你登录或验证账号归属。已有浏览器窗口可能需要手动进入 Vinted。
7. 完成后点击 **退出工具**，或在工具终端按 `Control+C`。关闭网页标签不会停止进程。退出工具不会关闭 AdsPower 浏览器。

API Key 只在这台 Mac 的当前工具进程中使用，不写入文件，不发往云端。连接后会清空网页的密钥输入框；重新连接时需要再次填写。页面刷新后需重新运行启动文件，从新打开的页面操作。不要分享终端中的本机会话地址。

如果 Mac 没有 Python，先从 [Python 官网](https://www.python.org/downloads/macos/) 安装 Python 3.9+ 的 macOS universal2 版本，再启动。无需安装 Xcode、Homebrew 或 Node.js。

## 工具行为和边界

- 新环境使用未分组（`group_id: "0"`）、本地直连、Chrome 最新内核与客户端默认设置，启动标签为所选 Vinted 站点。没有添加代理或定制反检测配置。
- 同名环境的设置、Cookie 和登录状态保持原样。重复点击或重新运行时先读取现有列表，减少重复创建；请只开一个工具实例操作。
- 请求按顺序发送并限制速率。额度不足等失败时停止后续创建，显示已完成结果。请求超时可能已经创建成功，应先重新检查列表，不会自动重试创建操作。
- 不导入 Cookie，不保存 Vinted／邮箱密码，不自动填写验证码，不批量注册、发布商品或交易。
- 只能管理这四个名称；没有删除、清空缓存、修改指纹或覆盖环境的接口。
- 浏览器启动成功表示 AdsPower 接受了启动请求，不代表 Vinted 页面已加载、账号登录成功或不会受限。请遵守平台账户规则。
- 脚本必须在 Mac 本机运行。GitHub 仓库和云端聊天不会因此获得你的 Mac 的远程控制权限。

## 常见问题

| 提示 | 处理方式 |
| --- | --- |
| 无法连接 | 保持 AdsPower 开启，检查 API 状态和端口。填写 AdsPower 端口，而不是管理页面地址里的端口。 |
| API 验证失败 | 从 AdsPower 本机复制 Key，确认套餐权限已生效。不要发送 Key 或关闭安全校验。 |
| V2 API 不存在 | 更新 AdsPower 并重启客户端，再检查 API 状态。 |
| 额度／请求限制 | 在客户端查看环境额度和 API 提示；重新检查列表后再决定是否继续。不会删除现有环境腾名额。 |
| 同名环境重复 | 在 AdsPower 中自行确认、重命名冲突的环境，然后重新检查。 |
| 运行后没自动开网页 | 在这台 Mac 的浏览器打开终端显示的完整本机地址。不要转发地址。 |
| 页面刷新后会话失效 | 工具不把会话存进浏览器持久存储。退出终端里的工具，再运行启动文件。 |
| 浏览器首次启动慢 | AdsPower 可能正在下载内核。在客户端检查进度；超时后先确认环境和窗口状态。 |

## 开发和验证

```bash
python3 -m unittest discover -s tests -v
node --check web/app.js  # 可选；只有验证 JS 语法时需要 Node.js
```

测试使用假的本机 AdsPower 服务，验证真实 HTTP 请求、分页、同名复用、部分创建失败后重跑、启动参数、密钥验证与本机页面会话保护。测试不会连接或更改真实 AdsPower。M 系列 Mac、真实 AdsPower 和 Vinted 登录仍需在你的电脑上验证。

接口依据：[AdsPower 页面提供的 Local API MCP 包](https://www.npmjs.com/package/local-api-mcp-typescript) `2.0.9` 中的 V2 接口定义（`browser-profile/list`、`create`、`start`）与 Bearer 验证格式。仅实现所需的三种操作。
