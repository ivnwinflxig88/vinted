MAC · ADSPOWER LOCAL API

管理前 4 个环境

在这台 Mac 上创建和打开 AdsPower 环境。Vinted 密码和验证码由你在浏览器中输入。

1. 连接本机 AdsPower

先打开 AdsPower → API & MCP，确认接口已启用。端口和 API Key 在此页面填写。

保持 AdsPower 的安全校验开启，并填写客户端生成的 Key。修改端口或站点后请重新连接。

2. 一次创建，逐个登录

同名环境会保留原设置和登录状态。请确认其中的账户，再决定如何使用。新环境使用本机网络与默认浏览器设置。

等待连接。工具只管理 Vinted-01 至 Vinted-04，不会删除其他环境。

API Key 仅保留在当前进程内存中。本工具不保证平台账户不会受限，请按平台规则使用。
